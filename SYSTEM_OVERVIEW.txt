🚀 HOW TO INTEGRATE (5 minutes)
════════════════════════════════════════════════════════════════════════════

1. Choose Email Service:
   • Resend (Easiest, recommended)
   • SendGrid
   • Nodemailer

2. Install Package:
   npm install resend
   (or sendgrid/mail or nodemailer)

3. Add .env.local:
   RESEND_API_KEY=re_your_api_key

4. Update src/lib/emailService.ts:
   • Import your email service
   • Replace sendOrderConfirmationEmail()
   • Add your API key

5. Update src/app/cart/page.tsx:
   • Import sendOrderConfirmationEmail
   • Call it in handleSubmitPayment()

6. Test & Deploy:
   npm run dev
   → Test checkout
   → npm run build
   → Deploy to production
